Hermes Light for your Linux desktop.

A remote-only graphical client for Hermes. Native Ubuntu / Kubuntu packages with automatic APT updates, and portable Linux AppImages. Connect to an existing remote Hermes gateway.

Install with APT

For Ubuntu / Kubuntu 24.04 (noble) or 26.04 (resolute). The commands install the repository GPG key and enable standard system updates.

set -e
base="https://dacog.github.io/hermes-desktop-light"
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL "$base/hermes-desktop-light.gpg" |
  sudo tee /etc/apt/keyrings/hermes-desktop-light.gpg >/dev/null
sudo chmod 644 /etc/apt/keyrings/hermes-desktop-light.gpg
codename="$(. /etc/os-release; printf '%s' "$VERSION_CODENAME")"
case "$codename" in
  noble|resolute) ;;
  *) echo "Unsupported Ubuntu base: $codename"; exit 1 ;;
esac
arch="$(dpkg --print-architecture)"
echo "deb [arch=$arch signed-by=/etc/apt/keyrings/hermes-desktop-light.gpg] $base $codename main" |
  sudo tee /etc/apt/sources.list.d/hermes-desktop-light.list
sudo apt update
sudo apt install hermes-desktop-light

Launch Hermes Light from your desktop's application menu. Debian package installation has passed CI smoke tests; GUI operation and connection to your gateway still need testing on a real device.
